# CS 330 Computational Graphics and Visualization

My final project is a 3D desert scene at sunset built in C++ and OpenGL, with two pyramids, two palm trees, a sand floor, and a setting sun. This repository holds the 3D scene ZIP folder and my design decisions document.

## How do I approach designing software?
This project taught me to break something complicated into simple pieces. I started with a 2D photo and asked what basic shapes each object really was, like a palm tree being just a cylinder with a flattened sphere on top. I planned the scene in Milestone One, then built it one layer at a time: shapes, camera, textures, and lighting. That same approach of planning first and breaking big problems into small ones will carry into any future project.

## How do I approach developing programs?
I worked in small steps and tested constantly. Every change got built and run right away, and flying the camera around caught problems I never would have spotted in the code, like a palm tree floating above the ground. Over the milestones I moved from copying and pasting drawing code to writing reusable functions like DrawPalmTree and DrawPyramid, which made the code shorter and much easier to change.

## How can computer science help me in reaching my goals?
My focus is cybersecurity. This course gave me a better understanding of how software talks to hardware through the GPU and how much behavior lives in code like shaders that is easy to overlook. Visualization also matters in security, since tools like network maps and dashboards help make large amounts of data readable. The habits I built here, like breaking down problems, testing as I go, and writing modular code, apply to any software I work on, in school and in my career.
